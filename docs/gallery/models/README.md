# Model Gallery

Interactive WebGL viewer for every `.mmd` mesh in
`FruitNinjaBada/Data/models/Fruit/` — all 115 fruits, bombs, blade FX,
and outlines. One model at a time, drag to orbit.

## Use

```bash
cd docs/model_gallery
python -m http.server 8080
# open http://127.0.0.1:8080/
```

- Left: single WebGL canvas rendering the selected model
- Right: filterable list of filenames + vertex counts
- Controls: auto-spin, port `-90° X rotation` (matches
  [`Mesh::Draw` port fix](../../src/engine/asset/Mesh.cpp)), wireframe,
  textured toggles
- URL hash (`#bomb.mmd`) tracks the selected model — bookmarkable

## Files

| File | Purpose |
|------|---------|
| `index.html` | Self-contained viewer. One WebGL context, one atlas texture, VBO/IBO swapped per selection. |
| `models.json` | Parsed geometry for every `.mmd` (positions, UVs, RGBA, indices, prim type, material/texture refs). Regenerated by `dump_meshes.py`. |
| `fruit_atlas.png` | Copy of `Data/models/fruit/textures/fruit_atlas.tex` decoded to PNG. Shared by every model the way the binary uses the single atlas. |
| `dump_meshes.py` | Python port of the `.mmd` loader. Re-run to regenerate `models.json` after asset changes. |

## Regenerating `models.json`

```bash
python docs/model_gallery/dump_meshes.py
```

The script walks `FruitNinjaBada/Data/models/Fruit/*.mmd` and writes
`models.json` next to itself. It's a straight port of the format
documented in
[`src/engine/asset/ResourceLoader.cpp`](../../src/engine/asset/ResourceLoader.cpp)
+ [`MeshManager.cpp`](../../src/engine/asset/MeshManager.cpp) — same
HBR0 chunk tree, same PSP GE vertex-declaration bitfield, same index
stream flag byte.

## Notes

- The viewer disables back-face culling because the Bada meshes have
  mixed winding (see the port's cull investigation in
  [`docs/engine/coordinate-system.md`](../engine/coordinate-system.md)).
  Disabling cull reveals every triangle, which is what you want for
  mesh inspection anyway.
- `applyPortRot` toggles the `-90°` around-X correction the port
  applies in `Mesh::Draw`. Leave it on to see fruits "upright" the way
  the port shows them; turn it off to see the raw mesh-authored
  orientation (every mesh has +Z as the "up" axis on disk).
- The atlas is sampled with `GL_CLAMP_TO_EDGE`, matching
  `DisplayManager::GetPlatformWrapS/T` in the port.
