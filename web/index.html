Fruit Ninja
Bada Port

An open-source reverse-engineered port of the original Samsung Bada version of Fruit Ninja, rebuilt with SDL2 + WebAssembly.
View source on GitHub

🍓

Play (Web)

Run the port directly in your browser via WebAssembly. No install required. Touch or mouse supported.

→ 🗡

Models Gallery

Interactive WebGL viewer for every mesh extracted from the original Bada binary — fruits, bombs, blade FX.

→ 🌞

Texture Gallery

All 452 textures decoded from the original .tex format: particles, HUD, fonts, and atlas sheets.
